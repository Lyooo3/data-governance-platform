# Vue 3 / FastAPI迁移交付

当前默认入口全部由src中的Vue组件构建，后端使用api中的Python模块。不执行原Vue 2编译资源、不使用旧工作台iframe；旧文件仅作参考。

## 页面范围

页面注册表包含58个路由入口：1个首页、6个概览、24个通用配置页、样例预览、流程、报告、预警、账号、审计各1个，以及21个明确的能力说明页。通用页共享组件，不代表58个独立业务引擎。

原标准、质量、资产、服务菜单已逐项核对，新增资源共享门户及原API开发子菜单入口。没有原数据库、审批、订阅、推送、对标或时效引擎的页面说明尚未启用，不虚构成功结果。业务数据库按要求不配置，初始数据源列表为空。

## 可以继续开发的内容

- 调整外观：src/styles/main.css。
- 调整门户、导航、登录：src/App.vue。
- 添加菜单与路由：src/router/pages.ts、index.ts。
- 修改业务页面：src/views中的.vue文件。
- 调整请求：src/api/client.ts。
- 添加Python接口：api/main.py或新APIRouter模块。
- 增加校验与节点：api/engine.py。
- 配置数据库：api/connectors.py当前为预留边界，storage.py为文件仓储。

前端和Python源码已格式化。Vue包含TypeScript检查、Vite开发服务、生产构建、懒加载及源码映射，不需要修改mock/bodies。

## 数据与升级

新版本使用.data-v3/state.json保存本地配置、账号、样例、结果和审计。不初始化SQLite，也没有MySQL驱动依赖。旧.data未读取、未修改、未自动导入。旧账号密码、数据源和流程不会自动出现在新版本中。

未来数据库接入时应增加仓储实现和凭据保护；当前文件仓储按单进程本机运行设计，不用于多worker或多人生产。数据库接入草稿不测试连接、不保存口令。

## 已验证

- Vue类型检查和生产构建成功。
- FastAPI的11项隔离测试通过，包含权限、保存、重启、流程、规则、预警、密钥、取消和超时。
- 浏览器从首页的数据治理进入质量模块，再进入流程；样例运行8条输入、7条输出、2条问题、71.43%合格率。
- 浏览器规则表单新增“记录编号唯一性”保存成功，关联record_code；该规则没有自动加入原示例流程。
- 原工作台地址跳转新版流程，原主模块旧地址跳转新版。
- Windows后端自动重载模式实测执行成功；为任务子进程使用专用Proactor事件循环，避免开发模式无法执行流程。Vite开发服务的API代理也已验证。

旧测试、接口实测清单和旧分析报告仅代表2.0版本。当前接口规范为API.md和在线/docs。依赖测试有一条Starlette对httpx测试适配器的弃用提示，测试结果正常，不影响运行服务。

## 使用

双击启动项目.cmd或npm start；浏览器访问http://127.0.0.1:4173/home。

开发时分别启动npm run api:dev及npm run dev，前端访问5173。生产修改后npm run build并刷新4173页面。安装、配置和扩展详细说明见根目录README.md。
