# 多数据库接入验收

版本3.4.0，2026-10-15。新增7种连接器，连同已有PostgreSQL共8种：PostgreSQL、MySQL、MariaDB、SQL Server、Oracle、SQLite、MongoDB、ClickHouse。所有类型复用“只读采集 → 本地原始库 → 治理副本 → 清洗、质量检查、报告”的流程。

## 边界

支持范围及认证级别以兼容矩阵为准，未宣称所有数据库及所有版本都已实库验证。连接器固定读取，不自动修改服务器权限或数据库级设置。ClickHouse、MongoDB单机以及非事务表的尽力读取不能提供整批时点一致性；MongoDB文档目前不自动扁平化。保持既有2000表/2GiB文本的采集限制及10,000行/100字段的治理副本限制，暂无跨表JOIN或实时CDC。
