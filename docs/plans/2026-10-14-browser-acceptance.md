# 浏览器全面验收与修复 Implementation Plan

**Goal:** 通过真实浏览器检查所有现有页面入口及独立按钮行为，修复可复现缺陷，记录未实现能力。

**Architecture:** Vue 3 页面经 FastAPI 保存到本地 SQLite。只使用验收数据验证写入、执行、查询和发布；原有业务数据与远程训练服务器保持不变。浏览器交互使用 CUA，接口与持久化回归使用现有 Python 测试。

**Tech Stack:** Vue 3 / TypeScript / Vite / FastAPI / SQLite / CUA。

## 1. 清单与保护

- 备份本地数据库，记录已有实体 ID 和数量。
- 从路由与真实 DOM 建立页面、按钮行为清单；每个共享页面实例也检查导航与标题。
- 新增数据使用“验收测试”前缀；删除、发布只针对测试数据，不触碰原有记录。

## 2. 浏览器验收

- 首页、顶部导航、侧边栏、面包屑、旧链接重定向。
- 登录、退出、错误密码反馈、只读权限。
- 15 类配置：新增、编辑、保存、取消、关闭、检索、筛选、分页、删除保护。
- 数据预览与分页，质量任务执行和预警处理。
- 7 类流程节点：添加、选择、配置、连入、连出、清线、删除、保存、执行。
- 运行列表、报告、步骤、结果、导出、取消运行。
- 服务注册、发布、字段白名单、查询及授权；审计和环境刷新。
- 未实现能力页：解释准确、跳转有效，单独记为未实现。

## 3. 缺陷修复

- 针对复现证据修改 src/views、src/components、src/App.vue 或 api。
- 涉及权限、流程、数据一致性的缺陷补充有意义的回归测试。
- 每次构建后浏览器刷新并复测受影响路径。

## 4. 完成交付

- 前端类型检查与生产构建；后端测试；SQLite 完整性检查。
- 验收记录明确通过、已修复、未实现和无法复现的范围，不虚报“全部可用”。
- 保存关键页面截图，保持项目运行，更新 README 的已知限制。
