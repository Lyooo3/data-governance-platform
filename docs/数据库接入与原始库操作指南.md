# 数据库接入与本地原始库操作指南

版本3.4.0，2026-10-15。

现在可在“数据库接入”直接只读采集PostgreSQL、MySQL、MariaDB、SQL Server、Oracle、SQLite、MongoDB和ClickHouse，无需逐表复制JSON。系统采用“业务库 → 本地原始库 → 治理副本 → 结果与报告”流程，远程库不执行写入。不同数据库的前提、范围与实测情况见[兼容矩阵](数据库兼容矩阵.md)。

## 1. 新增或再次采集数据库

1. 打开首页 → 数据接入 → 数据库接入 → 新增数据源。
2. 填名称并选择数据库类型，端口自动切换；网络数据库填主机IP或域名、实际端口、数据库名和账号。主机不含http://；服务器目录不是网络连接参数。Oracle选择Service Name或SID；MongoDB可指定认证库；SQLite改为后端机器已有文件的绝对路径，无需主机、账号或密码。保存只记录参数，不保存密码。
3. 需要加密时选择“必须加密”，私有证书填写后端本机CA路径；按实际TLS端口填写。选择快照一致性：严格模式不满足条件直接报错；ClickHouse及MongoDB单机需选尽力读取，接受采集期间源数据可能变化。点击记录的“连接与采集”，输入本次数据库密码（SQLite无需；MongoDB/ClickHouse按账号设置可留空），再点击“测试只读连接”。成功显示版本、只读及实际一致性。
4. 点击“扫描业务表”，可以按名称或说明筛选，勾选多张表；“全选当前筛选”追加当前筛选结果，“清空选择”取消所有勾选。
5. 点击“采集所选N张表”，或直接“采集全部业务表”。后者无需逐张选择。严格模式按连接器使用一致读取事务/会话，尽力读取明确记录限制；进度显示当前表、已完成表数和实际行数。MongoDB每个集合按一张原始表保存。
6. 完成后点击“查看本地原始库”。密码从页面清空；后续本地浏览、下载和治理无需密码。

估算行数来自数据库统计，可能为0或已过期；采集完成后的行数为实际读取数量。各连接器默认不含系统对象与视图，详细采集范围见兼容矩阵。PostgreSQL分区根表包含分区数据，避免重复采集子表。范围受当前账号读取权限限制。

任何一张所选表读取失败，整批标失败，不把部分数据标为全量完成；取消或中断后需新建采集批次。已有完整版本不会被覆盖。重新采集产生新版本，不会自动替换旧流程的数据源，也不是实时增量同步。

## 2. 浏览原始库并创建治理副本

1. 打开“数据接入 → 本地原始库”，选择快照与原始表。
2. “字段结构”显示原类型、主键、可空性和说明；“原始记录”分页浏览本地原值。
3. 下方填写副本名称、起始位置（0代表第一行）、最多行数、需要的字段，点击“创建治理副本”。界面会说明是全表还是部分副本。
4. “预览治理副本”检查数据，“配置质量规则”设置适合当前字段的规则，“编排治理流程”自动载入副本。

原始库可完整保存超过10,000行的表；当前治理引擎每次最多10,000行、100字段。大表可创建例如0～9999、10000～19999的不同区间副本。字段投影或部分行会在rawOrigin中记录，不能当作全表治理。

原始快照保留各连接器原值的文本表示及类型元数据，二进制为base64；MongoDB保存完整Canonical Extended JSON，不自动展开文档。治理副本将常规整数、短精度数值和布尔转为基础类型，超大整数、高精度数值、JSON/数组等保留文本；可用后续规则或清洗进行明确转换。此操作不修改原始库。

## 3. 编排与查看结果

从副本点击“编排治理流程”，自动预选读取的数据集与有字符串值的清洗字段；无字符串字段时直接生成读取、输出链路。可按需要添加质量检查、去重、过滤及字段映射节点，并依次连接。

添加质量节点后选择与当前表匹配的规则。不要沿用演示数据的org_name/score字段规则，除非当前表确有对应字段和相同业务含义。范围规则按真实分制定义。

保存并执行后，进入“运行与报告”查看输入输出、每步计数、规则结果和输出记录。可继续将成功结果登记为资产、创建数据服务及查看血缘；血缘能从副本追到本地原始库与原始表。

## 4. 存放、下载与备份

- 平台信息：`.data-v3/platform.sqlite3`。
- 原始库：`.data-v3/raw/<批次ID>.sqlite3`；页面“下载原始库SQLite”可另存。
- 原始库为SQLite逻辑快照，不是可原样恢复到PostgreSQL的物理克隆，不复制触发器、索引执行结构、序列、权限和程序。
- `npm run db:backup`生成平台备份及同名`.raw`目录，其中包含备份所关联的完整原始库。恢复时平台文件命名platform.sqlite3，原始文件放在新的GOV_DATA_DIR/raw/中。
- 采集一次只运行一个任务，最多2000表、2GiB原始记录文本；超限明确失败。治理仍为单表线性流程，暂不提供跨表JOIN或实时CDC。
- 8种数据库均有后端连接器，所有连接、采集、原始库API只允许管理员使用。SQL Server严格模式要求数据库已启用SNAPSHOT，系统不会自动更改远程设置。

## 5. 下次接入其他数据库

每个独立数据库新增一条数据源配置，不覆盖之前的数据源。按上述步骤采集后会得到独立原始库，各治理副本分别记录来源。可分别接MySQL、Oracle等，后续拖拽步骤相同。

本地已有“SQLite接入示例”：2表15行，可直接打开原始库、12行考试副本及“SQLite接入示例-考试清洗”流程查看操作效果。该示例为合成数据，原训练数据和报告仍保留。

连接设置遵循[psycopg事务参数](https://www.psycopg.org/psycopg3/docs/basic/transactions.html)；一致性与只读含义见[PostgreSQL事务文档](https://www.postgresql.org/docs/15/sql-set-transaction.html)。
